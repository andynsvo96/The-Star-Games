The room backdrop (`arcade-room.png`) and transparent title (`title.png`) were
created with the built-in image generation tool using the supplied toy arcade
reference. Both are bundled locally for host and browser use. See `PROMPTS.md`
for the exact generation prompts. No network access is required at runtime.

The molded board frame, glossy discs, sockets, and original thumbnail are local
SVG artwork. The earlier SVG background and vector title are retained as source
alternatives. Sound cues reuse the locally generated Tic Tac Toe sounds.
