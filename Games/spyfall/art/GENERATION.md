# Spyfall office artwork

`private-agent.png` is a generated transparent private-card portrait. It is
decorative and never contains a role, location, name or other private state.
Host and phone card layout, text and controls are real shared UI components.

## Private agent prompt

```text
Production transparent cutout UI illustration for a vintage Spyfall private dossier card. A single anonymous faceless spy, cropped at upper chest, wearing a wide fedora hat and trench coat with raised collar. Front view, head slightly lowered, all facial features obscured by a dark hat shadow; never depict a real person. Greyscale ink-black and warm charcoal shades with subtle sepia highlights. Painterly noir editorial illustration with restrained textured brushwork, matching an antique espionage office and aged parchment UI. Broad elegant clean silhouette and readable fedora shape; not cartoon, not a small blue app icon. Character centered, occupies 88% of a square 1024x1024 canvas. Transparent background all around with no backdrop, no paper, no frame, no text, no badges, no weapons. Cutout fades very gently at the bottom edge.
```

Generated with the built-in image_gen tool from the approved UI concepts. Production assets: spy-office.png. Original SVG sources remain in this folder. Background stems in the manifest are extensionless; host and controller media use the shared resolver.
