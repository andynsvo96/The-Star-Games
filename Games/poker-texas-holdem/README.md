# Texas Hold’em

Independent No-Limit Texas Hold’em mode in the Poker collection, stable ID
`poker-texas-holdem`. Two private cards; use any five cards from your hand and the
community board. Supports 2–10 total seats, including one human against AI.

See [Poker rules, presentation, saves and verification](../poker/README.md).
Preferences and unfinished sessions are independent of Omaha. Back returns to
the Poker chooser with the same admitted party.
