# Games Catalog

The launcher scans each direct child folder here for `game.json`. Folders beginning with `_` are ignored, so copy `_Template` to a lowercase game folder before customizing it.

See [`docs/CREATING_A_GAME.md`](../docs/CREATING_A_GAME.md) for the complete module contract. This file also ensures the otherwise-empty catalog directory is retained in initial packaged builds.
