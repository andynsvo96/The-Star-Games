# Omaha Hold’em

Independent four-card Pot-Limit Omaha High mode in the Poker collection, stable
ID `poker-omaha`. Use exactly two private and exactly three community cards.
Supports 2–10 total seats, including one human against AI. There is no low pot.

See [Poker rules, presentation, saves and verification](../poker/README.md).
Preferences and unfinished sessions are independent of Texas. Back returns to
the Poker chooser with the same admitted party.
