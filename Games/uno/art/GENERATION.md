# UNO artwork

The room was generated with the built-in imagegen tool and saved as
`Games/uno/art/game-room.png`. The attached user reference guided the style.
The final edit removes all chairs, per the user's correction. Colored player
boxes, card fans, names, counts, piles and private hands are runtime UI.

Initial prompt:

> Use case: stylized-concept. Asset type: offline 16:9 background illustration for a Godot UNO card game. The attached image is a STYLE AND COMPOSITION REFERENCE, not an edit target. Create a new matching polished cozy 3D illustrated game-room scene with warm lanterns, dark navy and purple tiled floor, wood-paneled walls, and an enormous honey-brown oval wooden table with a glowing gold rim viewed from above at a shallow angle. The table fills the central 80 percent of the frame, its center at image center, its upper edge near 18 percent and lower edge near 85 percent. Keep table surface COMPLETELY EMPTY for live cards. Six empty colored chair/seat pads around the perimeter at top-left red, top-right blue, mid-right green, lower-right yellow, lower-left purple, mid-left pink. Warm amber reflections, rich red/gold/blue contrast, glossy family party-game finish matching reference. Optional red framed UNO posters on upper side walls matching reference. NO hands, NO cards, NO decks, NO arrows, NO player names, NO counts, NO buttons, NO UI badges, NO gear icon, NO foreground hand or tray; all these are separately interactive layers. No people or faces. Wide landscape 16:9 composition, sharp high quality.

Final edit prompt:

> Edit this game-room background. Remove ALL SIX colored chairs/seats/pads from around the wooden table, replacing them seamlessly with the existing navy/purple tiled floor. No chairs or colored seats anywhere. Preserve the oval table, golden rim, camera, room, lanterns, wall posters, colors and lighting exactly. Table stays completely empty. Do not add boxes, UI, cards, text, arrows or controls. The game will draw colored player boxes itself at runtime.

Cards and the thumbnail are deterministic vector UI assets generated by
`generate_cards.ps1`. Lettering is converted to paths for identical offline
Godot/browser rendering. Regenerate on Windows with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Games/uno/art/generate_cards.ps1
```

The generator includes eight chosen-color Wild/Draw Four faces. These retain
the black card body and action mark while showing the selected color directly
on the face. Normal private-hand Wilds retain all four colors.

The user supplied `UNO_Logo.svg.webp`. Its unmodified original is preserved in
`asset/uno/UNO_Logo.svg.webp`; the identical offline runtime copy is
`Games/uno/art/uno-logo.webp`. It is used by the shared title-art component on
the host and by the browser header.

The rule/presentation split keeps each UNO deck independent while reusing the
same host table, private controller views and shared session lifecycle.

Skip and Reverse now repeat their vector action symbol at the center and both
corners. The corner marks use the same paths at a smaller scale, replacing S/R
lettering on all four colors and matching the user's supplied card reference.

## Flip card artwork

The existing Windows vector generator, `generate_cards.ps1`, also builds the
Flip light actions and black-bordered `flip-dark-*.svg` faces. They reuse the
Classic card geometry, outlined lettering, and action-symbol conventions.
Pink, teal, orange and purple identify the dark side; all fonts become paths
and every card loads offline on native hosts and browser controllers.
Wild Draw Two and both dark Wild sources use 4x native SVG imports for the
large color picker. Chosen-color variants retain the same underlying Wild face.

## No Mercy card artwork

The same vector generator also builds the colored Draw Four, Discard All,
Skip Everyone, Wild Reverse Draw Four, Wild Draw Six/Ten and Color Roulette
faces and all chosen-color Wild variants. Geometry, colors, outline lettering
and action marks follow the existing Classic/Flip cards. No raster generation
or remote media is required.

Gameplay follows the base
[Mattel instruction sheet](https://service.mattel.com/instruction_sheets/HVW18-Eng.pdf).
The sheet lists 168 cards but does not itemize multiplicities. The inventory
matches firsthand
[physical-deck counts](https://www.reddit.com/r/unocardgame/comments/16ywx33/card_list_uno_no_mercy/),
including the Draw Two correction: two of each 0–9 per color; three each Skip,
Reverse, Draw Two and Discard All per color; two each Draw Four and Skip Everyone
per color; eight each Wild Reverse Draw Four and Color Roulette; four each Wild
Draw Six and Ten. The base deck contains no plain Wild cards.


No Mercy uses a dedicated offline `no-mercy-*` vector set generated by
`generate_cards.ps1`: dark frames, black number ovals, transfer symbols on 0/7,
white-centered Wilds with colored card stacks/roulette faces, and red NO MERCY
backs. The source reference is [Mattel's UNO Show 'em No Mercy product and
instruction artwork](https://shop.mattel.com/products/uno-show-em-no-mercy-hwv18).
Color-selection `*-picker.svg` variants retain the existing ellipse sectors.
All lettering is converted to paths, so the host and controllers need no fonts
or external assets. Existing Classic and Flip files remain separate.

## Classic add-on artwork

`generate_addons.py` extends the existing Classic frames and colored ellipses
with original outlined labels and action symbols. It writes separate
`addon-*` and `addon-speed-*` SVGs, including chosen-color Wild variants.
Original card faces remain intact. Text is converted to paths with fontTools;
the generator defaults to Windows Arial Bold and accepts an alternate font
path as its first argument. Generation requires Python and fontTools, but the
game and controllers require neither. Run it from the repository root:

```text
python Games/uno/art/generate_addons.py
```

Inventory and actions follow Mattel's instruction sheets:
[Reverse](https://service.mattel.com/instruction_sheets/JCV56-Reverse.pdf),
[Stack](https://service.mattel.com/instruction_sheets/JCV58-Stack.pdf),
[Swap](https://service.mattel.com/instruction_sheets/JCV59-Swap.pdf),
[Speed](https://service.mattel.com/instruction_sheets/JCV57-Speed.pdf),
[Billie Eilish](https://service.mattel.com/instruction_sheets/JHG45_English.pdf),
[Frenemies](https://service.mattel.com/instruction_sheets/JMM16_2LB.pdf),
[Defense](https://service.mattel.com/instruction_sheets/JMM18_2LB.pdf),
[Comeback](https://service.mattel.com/instruction_sheets/JMM17_2LB.pdf), and
[Love Island](https://service.mattel.com/instruction_sheets/JPH28_DOM.pdf).
Love Island's three non-playable reference/placeholder cards are UI state.
Each other pack contributes 16 playable cards; Love Island contributes 13.
